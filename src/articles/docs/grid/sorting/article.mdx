# Sorting

The react-bootstrap-data-grid grid component implements interactive sorting of the rows in a grid. Sorting can be done
on a single column at a time.

## Enabling

Sorting for a grid is disabled by default. To enable sorting, enabling must be done for both the [Grid](/docs/ref/grid)
component and for individual columns inside the grid.

To enable sorting for individual columns, set the `sortable` property to `true` for the [ColDef](/docs/ref/col-def)
object for each column for which you wish to enable sorting.

```tsx
export const heroColumns: ColDef[] = [
  // other columns
  {
    type: "number",
    name: "damageMinLv1",
    label: "Damage Min Lv 1",
    width: 150,
    sortable: true
  },
  // other columns
];
```

To enable sorting for a [Grid](/docs/ref/grid) component, set the `sortModel` prop. See the following section for
examples.

## Controlled vs Uncontrolled

Like for several other features of react-bootstrap-data-grid, here are two ways to configure sorting for a grid
component, _controlled_ and _uncontrolled_.

__Controlled__ mode maximizes customizability by exposing the [state](https://react.dev/reference/react/useState) and
setter function to the parent component of the [Grid](/docs/ref/grid) component. Configure a grid to sort in controlled
mode by passing a prop of type [ControlledSortModel](/docs/ref/controlled-sort-model).

```tsx
const SortDemoGrid: FC = () => {
  const [sortColDef, setSortColDef] = useState<SortColDef | null>(null);

  return (
    <Grid
      rows={rows}
      cols={heroColumns}
      width="parent"
      sortModel={{ type: "controlled", sortColDef, setSortColDef }}
    />
  );
};
```

__Uncontrolled__ mode reduces the amount of code needed to configure sorting at the cost of the parent component losing
the ability to directly configure the column being sorted. Instead, the state of column being sorted is stored in the
[Grid](/docs/ref/grid) component itself. To enable sorting for a grid in uncontrolled mode, pass an
[UncontrolledSortModel](/docs/ref/uncontrolled-sort-model) as the `sortModel` prop.

```tsx
const SortDemoGrid: FC = () => {
  return (
    <Grid
      rows={rows}
      cols={heroColumns}
      width="parent"
      sortModel={{ type: "uncontrolled", initialSortColDef: null }}
    />
  );
};
```

## UI

The user may change the sort order for a grid by clicking on the header cell to cycle between sorting in the following
order:

- ascending
- descending
- none

One may also use keyboard navigation to select the header cell to control and then use the key bindings for clicking on
a button, generally <kbd>Enter</kbd> or <kbd>Space</kbd>, to cycle through sort orders with a keyboard.
