# Focus

Individual cells in the react-bootstrap-data-grid grid can be
[focused](https://developer.mozilla.org/en-US/docs/Web/API/HTMLElement/focus)
by either _clicking on the cell_ or using keyboard navigation.

Currently, the only feature that focusing on cells enables is copying the text contents of a cell. In the future, as
more features such as cell _selection_ and _editing_ are implemented, focusing will be integral to the use of those
features.

## Style

The grid component attempts to mimic Bootstrap's
[focus ring](https://getbootstrap.com/docs/5.3/helpers/focus-ring/)
helper to visually indicate focused cells.

[Color variants](https://getbootstrap.com/docs/5.3/helpers/focus-ring/#sass-utilities-api)
are also supported. To customize the color variant of the grid on a per-cell basis, pass functions to the
`headerCellFocusVariant` and `bodyCellFocusVariant` props to customize header cell and body cells, respectively. See the
[code sample](#example) below for more details on how to use this feature.

Additionally, the grid component obeys customizations to the Bootstrap
[Sass variables](https://getbootstrap.com/docs/5.3/helpers/focus-ring/#sass-variables)
related to focus rings.

## Keyboard Navigation

The grid component uses the
[roving tabindex](https://developer.mozilla.org/en-US/docs/Web/Accessibility/Guides/Keyboard-navigable_JavaScript_widgets#technique_1_roving_tabindex)
for the sake of accessibility. This means that when using the <kbd>Tab</kbd> and <kbd>Shift</kbd> + <kbd>Tab</kbd> keys to
navigate a web page containing the grid component, _only a single cell in the grid can be reached._ Pressing
<kbd>Tab</kbd> or <kbd>Shift</kbd> + <kbd>Tab</kbd> when focused on a cell in the grid will cause focus to leave the
grid.

To focus on different cells within a grid, instead one should use the following keys to navigate between cells. These
keys only work when focus is one of the cells inside a grid.

- <kbd>Right Arrow</kbd>: Moves focus one cell to the right. If already at the furthest-right cell, nothing happens.
- <kbd>Left Arrow</kbd>: Moves focus one cell to the left. If already at the furthest-left cell, nothing happens.
- <kbd>Down Arrow</kbd>: Moves focus one cell down. If already at the bottom-most cell, nothing happens.
- <kbd>Up Arrow</kbd>: Moves focus one cell up. If already at the top-most cell, nothing happens.
- <kbd>Home</kbd>: Moves focus to the first cell in the current row.
- <kbd>End</kbd>: Moves focus to the last cell in the current row.
- <kbd>Control</kbd> + <kbd>Home</kbd>: Moves focus to the first cell in the first row.
- <kbd>Control</kbd> + <kbd>End</kbd>: Moves focus to the last cell in the last row.

For Apple computers, use the <kbd>Command</kbd> key instead of the <kbd>Control</kbd> key.

## Copy Cell Contents

When focused on a cell, the user can copy the text contents of the cell by invoking the clipboard copy function of the
browser.

This feature is commonly invoked using the <kbd>Control</kbd> + <kbd>C</kbd> (<kbd>Command</kbd> + <kbd>C</kbd> on an
Apple computer) keyboard combination.

```tsx
"use client";

import { UnitStats } from "./types";
import unitData from "./sc1_unit_stats.json";
import Grid, {
  RowDef,
  ColDef,
  BodyCellVariantFn,
  HeaderCellVariantFn,
} from "@absreim/react-bootstrap-data-grid/grid";
import { FC } from "react";

// Data source: liquipedia

const rows: RowDef<UnitStats>[] = (unitData as UnitStats[]).map(
  (unit, index) => ({
    id: index,
    data: {
      ...unit,
    },
  }),
);

const cols: ColDef[] = [
  {
    type: "string",
    name: "unit",
    label: "Unit",
  },
  {
    type: "string",
    name: "race",
    label: "Race",
  },
  {
    type: "number",
    name: "pop",
    label: "Pop",
  },
  {
    type: "string",
    name: "size",
    label: "Size",
  },
  {
    type: "string",
    name: "minerals",
    label: "Minerals",
  },
  {
    type: "string",
    name: "gas",
    label: "Gas",
  },
  {
    type: "string",
    name: "armor",
    label: "Armor",
  },
  {
    type: "number",
    name: "hp",
    label: "HP",
  },
  {
    type: "number",
    name: "shield",
    label: "Shield",
  },
  {
    type: "string",
    name: "groundAttack",
    label: "Ground Attack",
  },
  {
    type: "string",
    name: "airAttack",
    label: "Air Attack",
  },
  {
    type: "string",
    name: "cooldown",
    label: "Cooldown",
  },
  {
    type: "string",
    name: "range",
    label: "Range",
  },
  {
    type: "string",
    name: "attackMod",
    label: "Attack Mod",
  },
  {
    type: "string",
    name: "sight",
    label: "Sight",
  },
  {
    type: "string",
    name: "notes",
    label: "Notes",
  },
  {
    type: "string",
    name: "buildTime",
    label: "Build Time",
  },
];

const getHeaderCellVariant: HeaderCellVariantFn = () => "primary";

const getBodyCellVariant: BodyCellVariantFn = (_, row) => {
  switch (row.contents[1].value) {
    case "Protoss": {
      return "info";
    }
    case "Zerg": {
      return "warning";
    }
    default: {
      return "success";
    }
  }
};

const FocusDemoGrid: FC = () => (
  <Grid
    rows={rows}
    cols={cols}
    width="parent"
    headerCellVariant={getHeaderCellVariant}
    headerCellFocusVariant={getHeaderCellVariant}
    bodyCellVariant={getBodyCellVariant}
    bodyCellFocusVariant={getBodyCellVariant}
  />
);

export default FocusDemoGrid;
```
